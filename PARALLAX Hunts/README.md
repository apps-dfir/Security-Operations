# PARALLAX Threat Hunts (WIP - Reach out to Apps, if you can find him!!)

PARALLAX is a threat hunting capability focused on identifying anomalous, rare, and behaviorally significant activity across enterprise telemetry.

**PARALLAX** stands for:

**P**attern  
**A**nalysis via  
**R**elational &  
**A**nomaly-based  
**L**ogic at  
**L**arge  
**A**cross  
**X**-domains  

The PARALLAX team conducts structured, hypothesis-driven threat hunts and documents them using the LOCK format (Learn, Observe, Check, Keep). This repository is the system of record for those hunts.

This repository is intentionally human-led. Analyst judgment, reasoning, and decision-making are preserved explicitly and are not replaced by automation.

## What this repository is
- A durable logbook of threat hunts
- A place to document how and why conclusions were reached
- A reference for future hunts and detection engineering

## What this repository is not
- A detection repository
- A response or containment platform
- An autonomous hunting system

## Starting point
January 2026 begins at LOCK Level 1. All hunts are executed and documented manually.
